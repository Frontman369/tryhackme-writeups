# Tcpdump: The Basics - TryHackMe Writeup

## Overview
This room introduced the fundamentals of Tcpdump, a command-line packet capture and traffic analysis tool widely used in networking and cybersecurity. The room focused on capturing network traffic, filtering packets, and analyzing communication directly from the terminal.

---

## Objectives
Throughout this room, I learned how to:
- Capture live network traffic from an interface  
- Save packet captures for later analysis  
- Apply filtering expressions to isolate relevant traffic  
- Control packet output and display formats for easier investigation  
- Analyze packet-level communication through terminal-based monitoring  

---

## Tools & Concepts Used
- Tcpdump  
- Packet capture (PCAP)  
- Filtering expressions  
- Network traffic analysis  
- Command-line packet inspection  

---

## Key Concepts

### Packet Capture
I learned how Tcpdump captures live packets directly from network interfaces and how those captures can be stored for future analysis.

---

### Filtering Expressions
The room introduced filtering techniques that allow specific traffic to be isolated based on protocols, hosts, ports, and other conditions.

This helps reduce unnecessary noise during packet analysis.

---

### Packet Display & Analysis
I explored how Tcpdump displays captured traffic and how output can be adjusted to reveal more detailed information during investigations.

---

### Command-Line Traffic Monitoring
Unlike graphical tools such as Wireshark, Tcpdump operates entirely through the command line, making it lightweight and highly useful for remote systems and servers.

---

## Challenges Faced
- Understanding filtering syntax and expressions  
- Interpreting packet information directly from terminal output  
- Following network traffic without graphical visualization  

---

## Key Takeaways
- Tcpdump is a powerful lightweight packet analysis tool  
- Filtering is essential when analyzing large amounts of traffic  
- Command-line packet inspection is valuable for remote and server environments  
- Packet captures can be saved and revisited for deeper analysis  

---

## Reflection
This room provided a practical introduction to terminal-based packet analysis. It demonstrated how network traffic can be captured and inspected efficiently without relying on graphical interfaces.

Working with Tcpdump also reinforced previous networking and protocol concepts by exposing how communication appears at the packet level in real time.
